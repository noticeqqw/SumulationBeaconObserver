# Симулятор маятника на пружине
> Физическая симуляция движения грузика на пружине с применением паттерна **Observer**

[![Java](https://img.shields.io/badge/Java-17-orange.svg)](https://www.oracle.com/java/)
[![Maven](https://img.shields.io/badge/Maven-3.8+-blue.svg)](https://maven.apache.org/)
[![JFreeChart](https://img.shields.io/badge/JFreeChart-1.5.3-green.svg)](https://www.jfree.org/jfreechart/)

---

## 📋 Описание проекта

Интерактивное приложение для симуляции физической модели **маятника на пружине** с возможностью:

- 🎮 Управления симуляцией (старт/стоп/сброс)
- ⚙️ Настройки физических параметров (масса, жёсткость пружины, затухание и др.)
- 📊 Визуализации параметров в реальном времени
- 📈 Построения графиков с использованием **JFreeChart**
- 🎯 Отображения траектории с помощью кастомного компонента **PointsPanel** (из ЛБ3)

Проект демонстрирует применение паттерна проектирования **Observer** для уведомления подписчиков об изменениях состояния симуляции.

## 🏗️ Архитектура

### Паттерн Observer

```
PhysicsController (Subject)
       │
       ├─── subscribe/unsubscribe
       │
       └─── notifies ──► SimulationObserver (Interface)
                              │
                              ├─── MainWindow
                              ├─── ChartWindow
                              └─── PointsChartWindow
```

## 🚀 Запуск проекта

### Требования

- **Java 17** или выше
- **Maven 3.8+**

### Настройка параметров

Доступные параметры:
- **Масса грузика** (кг)
- **Жёсткость пружины** (Н/м)
- **Естественная длина пружины R₀** (м)
- **Начальная длина пружины R** (м)
- **Начальный угол отклонения** (градусы)
- **Коэффициент затухания**
- **Ускорение свободного падения g** (м/с²)

### Графики параметров

Можно подписаться на любой из параметров:
- Угол (рад)
- Угловая скорость (рад/с)
- Длина пружины (м)
- Радиальная скорость (м/с)
- Координаты X, Y (м)
- Скорость (м/с)
- Сила пружины (Н)
- Сила тяжести (Н)
- Ускорение (м/с²)

**Два типа визуализации:**
- 📈 **JFreeChart** - профессиональная библиотека для графиков
- 🎯 **PointsPanel** - кастомный компонент из ЛБ3

## 🔬 Физическая модель

Система описывается дифференциальными уравнениями:

### Радиальное движение:
```
d²R/dt² = R(dφ/dt)² - (k/m)(R - R₀) + g·cos(φ) - (c/m)(dR/dt)
```

### Угловое движение:
```
d²φ/dt² = -(g/R)·sin(φ) - (2/R)(dR/dt)(dφ/dt) - (c/m)(dφ/dt)
```

Где:
- **R** - длина пружины
- **φ** - угол отклонения
- **k** - жёсткость пружины
- **m** - масса грузика
- **R₀** - естественная длина пружины
- **g** - ускорение свободного падения
- **c** - коэффициент затухания

Используется метод **Рунге-Кутты 4-го порядка** для численного интегрирования.

## 🎨 Особенности реализации

### Паттерн Observer

- **Subject**: `PhysicsController` - управляет симуляцией и уведомляет наблюдателей
- **Observer**: `SimulationObserver` - интерфейс для подписчиков
- **Concrete Observers**: `MainWindow`, `ChartWindow`, `PointsChartWindow`

### Многопоточность

- Симуляция выполняется в отдельном потоке
- Обновление GUI происходит через `SwingUtilities.invokeLater()`
- Используется `CopyOnWriteArrayList` для безопасной работы с подписчиками

### Численное интегрирование

- Шаг интегрирования: **0.001 сек**
- Частота обновления GUI: **~60 FPS**
- Метод: **Рунге-Кутта 4-го порядка**
